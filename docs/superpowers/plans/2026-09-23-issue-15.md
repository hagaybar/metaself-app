# The weight chart reads like a chart — public issue #15

**Goal:** public issue #15 ("The weight chart is a line floating on a page"). The owner chose
**option A, the quiet grid** (decision comment on the issue, 2026-09-23). Rejected there, and not
built: a weekly min–max band, and trend-only with the distance to goal shaded.

**Spec:** no numbered decision changes. The 2 kg minimum span (`MIN_SPAN_KG`), the goal-drops-off
rule (`GOAL_STAYS_WITHIN`), the range filter and the stored chart range all stay exactly as they are;
the new drawing is laid over the same `ChartGeometry`. No charting library, no new dependency.

**Before every Gradle command:** `export ANDROID_HOME=/home/ubuntu/android-sdk`; use
`~/bin/gradlew-safe`; redirect output to a file and check `$?`; stage by explicit path.

## What is drawn

| Element | How |
|---|---|
| Gridlines | Horizontal hairlines (`outlineVariant`) at whole kilos. Step is 1, 2, 5, 10, 20 or 50 kg: the smallest that leaves at most six gaps across the axis span. |
| Gridline labels | At the right edge, in a gutter the plot does not draw into, in the caption ink (`onSurfaceVariant`, ink step three), `labelMedium` (tabular figures). Bare numbers; the top one carries "kg". |
| Dates | Under the plot: first and last always, month starts between them where they fit without touching a neighbour. |
| Trend | The heavy line, in ink (`onSurface`). |
| Readings | Small dots (`secondary`), opacity 1 until dots start to touch, then falling with readings per dp, floored. |
| Goal | The dashed teal (`tertiary`) line, with an inline "Goal N kg" label, N formatted as `GoalWording` formats kg. |
| Scrub | Hold, then drag: a vertical hairline, a ring on the trend, and above the chart the day, "Trend 81.9" and — only when a reading exists that day — "Weighed 81.6". A light tick (`Feel.Tick`) each time the finger reaches a day with a reading. Release clears it. |
| Screen reader | The plot carries a one-sentence summary: range of dates, trend at each end, goal if drawn. |

A day with no reading reads the trend off the line as drawn (linear between the two readings either
side), so the ring sits on the line and the readout agrees with it.

No animation is added, so "Remove animations" is respected trivially.
