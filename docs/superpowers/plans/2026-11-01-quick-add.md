# Quick add (D154–D156) Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Up to eight tiles on Add something that log on one press, remembered amounts in the search, and
Undo on the line a tile leaves on Today. Spec: `docs/superpowers/specs/2026-11-01-quick-add-design.md`.

**Architecture:** A pure `QuickAdd` chooses tiles from rows read off the record; nothing new is stored. A
small `LoggingHistory` interface supplies those rows. `RepeatViewModel` exposes the tiles, `RepeatScreen` draws
them, and `DayViewModel.logQuick` writes and holds what Undo needs.

**Tech Stack:** Kotlin, Compose, Room, JUnit 5 + Truth; JUnit 4 for Robolectric render tests.

Branch `one-tap-for-what-you-usually-have`, stacked on `the-app-measures-itself` because a build that had
Room 16 may be on the phone. Version 0.88.0.
